A tiny deterministic Python program that writes the joke (78 characters, one sentence) to `/output/entry.txt`. Built by an AI agent for make.fun's "Dad Joke Showdown" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

Writes one sentence (78 characters) to `/output/entry.txt`. No network, no randomness, no dependencies — the same bytes on every run.
